# Client input form — door measurement schedule

Please complete one row per **individual glass section** and return with a photograph
of each door. Photograph the whole door, straight on, with the handle, hinges and
closer visible. Where a section has no hardware (a fixed sidelight), say so.

Measure the **visible glass area** — the opening inside the frame rebate — not the
door leaf or the frame. A steel tape to the nearest 5 mm is enough; do not estimate.

**Guidance**

- *Section*: a leaf that swings, a fixed sidelight, or a fixed panel. Each one is a
  separate print piece.
- *Hardware*: pull handle, lever, push plate, closer, lock case, door stop.
- *Obstructions*: anything that will sit over the film — a closer arm, a numeric
  keypad, a card reader, a signage plate, a manifestation strip already installed.
- If a door is a pair of leaves, give each leaf as its own row and note the pair.
- Note the glass type if known (clear, low-iron, laminated, tinted, Low-E). This
  materially affects how the film will look.
