# Generative AI: From First Prompt to First App

**A free, beginner-friendly course. No coding experience required to start — and you'll be building real AI apps by the end.**

---

## Who this course is for

You are in the right place if:

- You have **used** ChatGPT (or heard of it) but feel like you're only scratching the surface.
- You've never written a line of code, **or** you know a little Python and want to build with AI.
- You want practical skills — writing, research, image generation, data analysis, automation — not theory.
- You want to understand what's actually happening, so you can tell when the AI is confidently wrong.

**You do not need:** a powerful computer, a paid subscription, a maths background, or any prior AI experience.

**You will need:** a phone or computer, an internet connection, and about 30 minutes per lesson.

## How the course is structured

The course is in **four parts**. Parts 1 and 2 need nothing but a web browser. Part 3 is where you start writing code. Part 4 is where you prove it.

```
Part 1  ──  Foundations          Understand it, prompt it, trust it correctly
Part 2  ──  Creative work        Text, images, video, audio, data
Part 3  ──  Building with code   APIs, prompts in code, real apps
Part 4  ──  Projects             Four capstone builds
```

> **Skipping ahead is allowed.** If you already prompt confidently, jump to [Part 2](./08-images.md). If you already code, jump to [Part 3](./11-setup-python-and-api-keys.md). Every lesson is self-contained.

## The three rules of this course

**1. Do the exercises.** Reading about prompting teaches you almost nothing. Every lesson has a short hands-on task. Do it, even if it feels small. The skill is in your hands, not your head.

**2. Never ship unchecked output.** AI is confidently, fluently wrong surprisingly often. Module 5 is not optional — it's the module that keeps you out of trouble.

**3. Build something you actually want.** The projects in Part 4 are templates. Change them to solve a problem you have. A tool for your own work beats a demo you don't care about.

## A note on how fast this field moves

Model names, prices, and features change every few months. This course was last verified in **September 2026**.

I've written it to **teach the durable ideas** — how to specify what you want, how to iterate, how to verify — because those don't change. Where a specific model name or price appears, treat it as *"this was true when written; check the link to confirm."* Every such claim links to the official source.

If something here is out of date, that's a bug. [Open an issue](https://github.com/Gide26/Gide26/issues) and it'll get fixed.
